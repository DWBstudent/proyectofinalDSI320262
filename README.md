# proyectofinal

Sistema academico tipo SALA para la Universidad El Bosque. Proyecto final de Desarrollo de Sistemas de Informacion 3.

## Descripción General

Aplicación web donde el estudiante consulta su ruta de carrera, sus notas y promedios e inscribe materias; el docente sube notas de sus grupos, y el administrador gestiona materias, periodos y la auditoría.

## Estructura del repositorio

- "back": API REST en Spring Boot
- "front": aplicación Angular
- "docs": convenciones, diagramas, acta de constitución y manual de usuario
